# food-safety-fair-data
This file represents a FAIR-compliant JSON-LD framework for integrating aflatoxin contamination data across Mali, Niger, and Burkina Faso in maize, groundnut, and sorghum value chains.  #Features  *FAIR Data &amp; JSON-LD: Standardized semantic schema. *Unified Scope: Unifies lab results, GIS metadata, and intervention records.
